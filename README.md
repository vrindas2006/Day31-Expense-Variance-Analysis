# Day 31 – Expense Variance Analysis

## 📌 Project Overview

As part of my 45-Day Data Analytics Internship, I worked on an Expense Variance Analysis project using Excel and Power BI.

The objective of this project is to compare actual expenses with the allocated budget, calculate variance and variance percentage, identify material gaps, and present the results through an interactive dashboard.

## 🎯 Objectives

- Compare budgeted expenses with actual expenses
- Calculate absolute variance
- Calculate variance percentage
- Identify over-budget and under-budget expenses
- Identify material gaps
- Analyze expenses by department and category
- Build an interactive Power BI dashboard

## 🛠️ Tools Used

- Microsoft Excel
- Power BI
- DAX
- PivotTables
- Conditional Formatting

## 📊 Key Analysis

The analysis includes:

- Total Budget
- Total Actual Expenses
- Total Variance
- Variance %
- Department-wise Budget vs Actual
- Category-wise Variance
- Over Budget vs Under Budget analysis
- Material Gap identification

## 📈 Dashboard Features

The Power BI dashboard includes:

- KPI cards for Budget, Actual, Variance and Variance %
- Budget vs Actual by Department
- Variance by Expense Category
- Interactive Department slicer
- Month, Category and Status filters
- Detailed expense analysis
